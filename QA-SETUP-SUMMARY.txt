MONITORING PATTERNS:

Find errors:
  docker compose logs -f | grep '"level":"ERROR"'

Find slow responses (>1000ms):
  docker compose logs -f | grep -E '"duration_ms":[0-9]{4,}'

Track specific request:
  docker compose logs | grep 'req_abc12345'

Find status codes:
  docker compose logs | grep '"status":5'  # 5xx errors
  docker compose logs | grep '"status":4'  # 4xx errors

Save logs:
  docker compose logs > logs_$(date +%Y%m%d_%H%M%S).txt

TROUBLESHOOTING:

Q: Where are logs?
A: Browser console (F12 > Console tab) when using npm run dev
   Or terminal when using docker compose logs -f

Q: Logs not JSON format?
A: Check NODE_ENV is "development"
   Verify browser console is open

Q: No logs appearing?
A: npm run dev must be running
   Open browser to http://localhost:3000
   Perform an action in app

Q: Docker error?
A: Docker is optional - npm run dev works without it
   Install Docker from https://docker.com if you want docker compose logs

Q: Can't find request ID?
A: Look for "req_" prefix in logs
   Format: req_abc12345

LOGGING API REFERENCE:

Basic Usage:
  import { logger } from '@/lib/logger';

  logger.info('Message', { request_id: 'req_xxx', key: 'value' });
  logger.warning('Message', { request_id: 'req_xxx', key: 'value' });
  logger.error('Message', { request_id: 'req_xxx', key: 'value' });
  logger.debug('Message', { request_id: 'req_xxx', key: 'value' });

API Client:
  import { apiPost, apiGet, apiPatch, apiDelete } from '@/lib/api-client';

  // Automatic logging
  const result = await apiPost('/consultations', data);
  const list = await apiGet('/consultations');

Generate Request ID:
  import { generateRequestId } from '@/lib/logger';

  const id = generateRequestId(); // Returns "req_abc12345"
