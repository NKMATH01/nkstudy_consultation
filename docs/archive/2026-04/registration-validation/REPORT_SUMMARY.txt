핵심 내용 요약
================================================================================

버그:
------
사용자가 영어 과목만 있는 새 반을 생성한 후 등록 안내문을 생성하려 할 때,
UI에는 영어 필드만 표시되지만 수학 필드의 validation 에러 발생.
→ 사용자가 선택할 수 없는 필드에 대한 에러로 UX 저해.

근본 원인 (3가지):
-------------------
1. Validation 스키마: assigned_class, teacher를 무조건 필수로 설정
   → 과목이 영어만일 때도 수학 필드를 요구함

2. Form 핸들러: 반 선택 시 parseClassSchedule() 결과를 무조건 setValue()로 덮어쓰기
   → 스케줄 미설정 반이면 빈값으로 강제 덮어쓰기

3. Server Action: createRegistration과 regenerateRegistration에서
   영어 과목 시 영어반 스케줄 DB 조회 누락
   → 영어 과목에만 스케줄 정보 미수록

해결 방법:
-----------
1. Validation: z.object().refine()로 조건부 필수 필드 구현
2. Form handler: if (schedule.data) 체크 후에만 setValue() 호출
3. Server: if (["영어", "영어수학"].includes(subject)) 조건 추가

결과:
------
✅ 영어 과목 등록 안내문 생성 기능 완성
✅ Form 핸들러 안정성 개선
✅ 서버 영어 과목 스케줄 처리 완성
✅ Match rate: 95%
✅ Build status: PASS
✅ TypeScript errors: 0
✅ All manual tests: PASS

수정 파일 (3개):
-----------------
1. src/lib/validations/registration.ts (validation schema)
2. src/components/registrations/registration-form-client.tsx (form handlers)
3. src/lib/actions/registration.ts (server actions)
