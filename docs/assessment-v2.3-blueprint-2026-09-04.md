# NK 입학 학습성향 검사 v2.3 문항표(초안) — 결과지 질문 9개에 답하는 구성

> 2026-09-04 사용자 요청으로 다시 짠 문항표 **초안**이다. 코드는 아직 한 줄도 바꾸지 않았다.
> 학부모 결과지 아트보드는 `docs/prototypes/2026-09-04-parent-report-v3/Main.dc.html` 이며 이 문항표를 전제로 그렸다.

결과지에서 답해야 할 질문 아홉 개는 다음과 같다.

1. 학습 태도 — 공부를 얼마나 열심히 하는가?
2. 숙제 태도 — 숙제를 열심히 하는가?
3. 목표 의식 — 구체적인 목표가 있는가?
4. 현재 학습의 어려운 점은 무엇인가?
5. 단기 회복력 — 강사가 힘들게 시켜도 따라올 것인가?
6. 질문 성향 — 활기차게 질문하는 편인가?
7. 학습 방해 — 친구나 휴대폰 때문에 공부를 제대로 못 하는가?
8. ★ 철저한 관리를 버틸 수 있는가?
9. ★ 강하게 밀어도 되는가, 차분히 다독여야 하는가?

## 1. 원칙

- 질문 아홉 개에 **척도 하나씩** 답한다. 한 척도는 문항 4개로 만든다(회복력·관리 수용은 5개).
- 한 문항에는 **한 행동**만 담는다. 문장은 초등학생이 읽어도 뜻이 하나로 잡히는 20자 안팎으로 쓴다.
- 회상 기간은 **최근 2주**이며 화면 안내로 통일한다. 경험을 묻는 문항만 `지금까지`로 안내한다.
- **역문항은 척도당 최대 1개**로 둔다.
- 지적·낮은 점수·남아서 보충처럼 기회가 없을 수 있는 문항에는 `경험 없음`을 허용하고, 그 문항은 평균에서 뺀다.
- 채점: 응답 1~5 → `(응답 − 1) ÷ 4 × 100`. 역문항은 뒤집는다. 척도 점수는 문항 점수의 평균이다.
- 등급: **잘 되고 있음 ≥ 75 / 지켜볼 것 62.5 이상 75 미만 / 먼저 도울 것 62.5 미만.**
  3점(`절반쯤 했다`·`반반이다`)은 50점이므로 '보통'이 아니라 **먼저 도울 것**이다.
- 직접 질문 두 개(관리 수용 `E5`, 지도 방식 `F5`)는 **점수에 넣지 않는다.** 학생이 고른 답을 원문 그대로 판정에 쓴다.
- 응답 표지는 현재 코드(`src/lib/assessment/v2/display.ts`)의 값을 그대로 쓴다.
  - 빈도 — `거의 하지 않았다 / 가끔 했다 / 절반쯤 했다 / 대부분 했다 / 할 때마다 했다`
  - 동의 — `전혀 맞지 않다 / 별로 맞지 않다 / 반반이다 / 대체로 맞다 / 매우 잘 맞다`
- 출처 표기 — `유지 LT1`은 행동과 뜻을 그대로 두고 문장만 짧게 다듬은 것, `수정 H4`는 묻는 행동을 바꾼 것, `신규`는 새로 만든 것이다.

## 3. 학부모 질문지 (결과지 맨 아래)

결과지 마지막 섹션 `학부모님께 여쭙니다`에 넣는다. 부제는 `상담 전에 표시해 주시면 상담이 빨라집니다.`
학부모가 종이나 화면에서 표시하는 칸이며 **점수를 내지 않는다.** 입학 상담에서 함께 본다.

| 번호 | 질문 | 보기 |
|---|---|---|
| 1 | 학생에게 강한 학습(철저한 관리, 많은 숙제)을 원하시나요? | `원한다` / `적당히` / `부담 없이` |
| 2 | 이 결과지가 파악한 학생 모습이 학부모님 생각과 같으신가요? | `같다` / `대체로 같다` / `다르다` + 빈 답란 `다른 점:` |
| 3 | 학원에서 연락을 얼마나 자주 받고 싶으신가요? | `매주` / `2주에 한 번` / `한 달에 한 번` / `필요할 때만` |
| 4 | 공부 문제에서 학생의 요구에 끌려가는 편이신가요? | `그렇다` / `반반이다` / `아니다` |
| 5 | 좋은 대학 진학이 목표인가요? | `그렇다` / `아직 정하지 않았다` / `다른 목표가 있다` + 빈 답란 |
| 6 | 이번 시험의 목표 점수는 몇 점인가요? | 빈 답란 `___점` — 수학 / 영어 두 칸 |
| 7 | 학생이 힘들어할 때 학원이 어떻게 해 주길 원하시나요? | `강하게 밀어 주기` / `다독여 주기` / `학부모와 먼저 상의` |

1번과 7번은 학생의 `E5`(관리를 버틸 수 있는가)와 `F5`(강하게 밀어도 되는가)에 대한 **학부모 쪽 답**이다.
둘이 어긋나면 상담에서 먼저 맞춘다. 2번은 결과지가 맞았는지 확인하는 칸이다.

**결과지에서 `입학 상담에서 확인할 것` 목록은 뺐다.** 그 자리를 이 질문지가 대신한다.
자리 번호는 그대로 10이며 섹션 번호는 01~10으로 이어진다.

## 4. 판정 규칙

### 4.1 철저한 관리를 버틸 수 있는가

`E 점수` + `E5 본인 답` + `D 점수`로 정한다.

| 판정 | 조건 |
|---|---|
| 버틸 수 있음 | E ≥ 75 **그리고** E5 ∈ {버틸 수 있다, 힘들어도 해 보겠다} **그리고** D ≥ 62.5 |
| 지금은 어려움 | E5 = 힘들 것 같다 **이거나** (E < 62.5 **그리고** D < 62.5) |
| 도움이 있으면 버팀 | 위 둘에 해당하지 않는 나머지 전부 |

판정마다 근거 문장을 한 개씩 붙인다. 어느 척도와 어느 직접 답에서 나왔는지 밝힌다.

- 버틸 수 있음 — `남아서 하라고 하면 남았고, 힘든 구간에서도 다시 시작한다고 답했습니다.` (근거: 관리 수용 E1·E4, 단기 회복력 D2·D3)
- 도움이 있으면 버팀 — `관리를 받아들이겠다고 답했지만, 결과가 늦게 나오는 구간에서 한 번 멈추는 쪽입니다.` (근거: 관리 수용 E5 본인 답, 단기 회복력 D2)
- 지금은 어려움 — `관리가 힘들 것 같다고 직접 답했고, 힘든 뒤 다시 시작하는 응답도 낮았습니다.` (근거: 관리 수용 E5 본인 답, 단기 회복력 D 전체)

### 4.2 강하게 밀어도 되는가, 차분히 다독여야 하는가

`F 점수` + `F5 본인 선택`으로 정한다.

| F 점수 | 판정 |
|---|---|
| 75 이상 | 강하게 밀어도 됨 |
| 62.5 이상 75 미만 | 강하게 하되 다독임을 같이 |
| 62.5 미만 | 차분히 다독이며 |

F5가 점수와 반대 방향이면 **한 단계 가운데로 당기고** `상담에서 확인`을 붙인다.
이미 가운데 판정이면 그대로 두고 `상담에서 확인`만 붙인다.

- ⓐ를 골랐는데 F < 62.5 → `차분히 다독이며` → `강하게 하되 다독임을 같이` + 상담에서 확인
- ⓑ를 골랐는데 F ≥ 75 → `강하게 밀어도 됨` → `강하게 하되 다독임을 같이` + 상담에서 확인

### 4.3 나머지 질문의 한 줄 답

척도 등급을 그대로 문장으로 바꾼다. 결과지 04의 첫 줄에 쓴다.

| 질문 | 척도 | 잘 되고 있음 | 지켜볼 것 | 먼저 도울 것 |
|---|---|---|---|---|
| 공부를 얼마나 열심히 하는가 | A | 열심히 합니다. | 절반쯤 합니다. | 아직 열심히 하는 습관이 없습니다. |

부르는 이름을 만들지 않는다. MBTI를 원인으로 쓰는 문장도 쓰지 않는다.

## 부록. 결과지 예시(서민준·중2·수학) 값

결과지 아트보드의 그래프는 아래 값으로 그렸다. 문항 값은 `0 / 25 / 50 / 75 / 100` 다섯 자리만 쓴다(응답 1~5에 대응). 역문항은 뒤집은 값이다.

| 척도 | 문항 값 | 평균 | 결과지 표기 | 등급 |
|---|---|---|---|---|
| A 학습 태도 | A1 100 · A2 75 · A3 75 · A4 75 | 81.25 | 81 | 잘 되고 있음 |
| B 숙제 태도 | B1 75 · B2 100 · B3 75 · B4 75 | 81.25 | 81 | 잘 되고 있음 |
| C 목표 의식 | C1 50 · C2 25 · C3 75 · C4 50 | 50.00 | 50 | 먼저 도울 것 |
| D 단기 회복력 | D1 75 · D2 25 · D3 75 · D4 50 · D5 50 | 55.00 | 55 | 먼저 도울 것 |
| E 관리 수용 | E1 100 · E2 75 · E3 75 · E4 25 | 68.75 | 69 | 지켜볼 것 |
| F 지도 방식 반응 | F1 75 · F2 50 · F3 75 · F4 75 | 68.75 | 69 | 강하게 하되 다독임을 같이 |
| G 질문 성향 | G1 50 · G2 50 · G3 25 · G4 75 | 50.00 | 50 | 먼저 도울 것 |
| H 휴대폰 | H1 75 · H2 50 · H3 75 · H4 75 | 68.75 | 69 | 지켜볼 것 |
| H 친구 | H5 50 · H6 50 · H7 75 | 58.33 | 58 | 먼저 도울 것 |
| 수학 공부 방식 | 조건 정리 75 · 대안 탐색 75 · 풀이 기록 50 · 오류 분류 50 · 검산 75 · 함께 복습 75 | 66.67 | 67 | 지켜볼 것 |

직접 질문 — E5 `힘들어도 해 보겠다` / F5 ⓑ `먼저 잘한 점을 말하고 차분히 고쳐 주는 선생님`

판정 — 관리 수용: E 69(75 미만) · E5는 허용 답 · D 55(62.5 미만) → **도움이 있으면 버팀**.
지도 방식: F 69 → **강하게 하되 다독임을 같이**. F5가 다독임 쪽이라 상담에서 확인을 붙인다.

### 그래프 좌표 규칙

- 3구간 띠 — 마커 위치(%)는 척도 점수와 같다. 구간은 62.5 / 12.5 / 25 비율이다.
- 레이더 — 중심 `(175, 148)`, 반지름 `점수 ÷ 100 × 88`. 안쪽 원 55는 62.5, 바깥 원 66은 75다.
- 점 스트립 — 가로 눈금 `24 / 92 / 160 / 228 / 296`이 각각 `0 / 25 / 50 / 75 / 100`이다.
- 지도 방식 사분면 — 가로 `x = 46 + 2.8 × 값`, 세로 `y = 200 − 1.8 × 값`. 마커는 (75, 62).
  가로축은 F1 값 75다. 세로축 62는 `혼난 뒤 피하지 않음`으로, F2 뒤집은 값 50과 D3 75의 평균 62.5다.

### 응답 분포(46문항)

`거의 하지 않았다 1 · 가끔 했다 5 · 절반쯤 했다 14 · 대부분 했다 17 · 할 때마다 했다 8 · 경험 없음 1`
