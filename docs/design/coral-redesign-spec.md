# 코럴 리디자인 스펙 (신입생 프로그램 대시보드 개편)

> 사용자 제공 스펙 전문. 5단계로 나눠 진행하며 각 단계마다 검수·확인 후 다음 단계로 넘어간다.
> 작업 브랜치: `feature/coral-redesign` (master 커밋 금지, push 금지).
>
> **Tailwind v4 참고**: 이 프로젝트는 `tailwind.config`가 없다(Tailwind v4). 스펙의 커스텀 컬러
> (coral, coral-deep, coral-soft, teal, bg-page 등)는 2단계에서 `src/app/globals.css`(또는 전용 CSS)의
> `@theme { --color-... }` 토큰으로 등록할 계획이다. 효과는 tailwind.config `theme.extend.colors`와 동일하며,
> 등록 후 `bg-coral`, `text-coral-deep` 같은 유틸리티를 그대로 사용할 수 있다. 1단계는 구조 뼈대만 다루고
> 정확한 컬러 시스템은 2단계에서 토큰으로 도입한다.

---

## 사용자 스펙 전문

### [전체 레이아웃]
상단 고정 헤더(GNB): 흰색 배경+하단 옅은 웜톤 구분선. 왼쪽 로고(코럴 배경 둥근 사각형 안 흰색 학원 이니셜). 가운데 큰 카테고리 메뉴 3~4개 — 이름은 [카테고리1][카테고리2][카테고리3] 자리표시자, src/constants/menu.ts 상수로 분리. 활성 카테고리는 연한 코럴 배경(pill)+코럴 텍스트, 비활성은 웜 그레이. 오른쪽 알림 아이콘+사용자 아바타(연코럴 원형).

좌측 사이드바(200px): 상단 헤더 카테고리에 따라 세부 메뉴 세트 통째 교체. 세부 메뉴도 [세부메뉴A][세부메뉴B] 자리표시자 상수. 하위 항목 있는 메뉴는 chevron 접기/펼치기. 선택 메뉴: 연코럴 배경(#FFF3ED)+진코럴 텍스트+왼쪽 3px 코럴 세로 라인. 비선택: 웜 그레이, hover 옅은 배경.

메인 콘텐츠(위→아래): 현황 요약 카드 3~4개("전체 OO","이번 주 OO","대기 중 OO" — 라벨 작은 웜그레이, 숫자 크고 진하게, 주의 숫자는 코럴). 필터 바(왼쪽 pill 토글 전체/초/중/고, 오른쪽 검색창+코럴 "+ 만들기" CTA rounded-full). 목록 카드: 행 단위 [학년 뱃지|제목(+NEW 뱃지)·부제목 2줄|날짜|액션 버튼], hover 배경 transition.

### [디자인 시스템]
커스텀 컬러: coral #F0653A(로고·활성·CTA) / coral-deep #C7521F(연코럴 배경 위 텍스트·뱃지 텍스트) / coral-soft #FFF3ED(활성 탭·선택 메뉴·뱃지 배경) / teal #2D6A6A(NEW 뱃지 등 소량) / bg-page #FFFBF9(순백 금지) / bg-card #FFFFFF / text-main #3A342F / text-sub #8B8078 / text-hint #A59A90 / line #F0E4DD / line-soft #F8EEE8 / row-hover #FFF8F4.

공통 규칙: Pretendard(CDN), 제목 font-medium~semibold. 카드 rounded-2xl, 테두리 0.5px 수준, shadow-sm 이하. 버튼/뱃지/필터 전부 pill(rounded-full). 아이콘 lucide-react. 구분은 선보다 여백·배경색으로, 회색 테두리 남발 금지. 카드 padding 16~20px, 섹션 margin 24px+. 원색 코럴은 CTA·활성 pill·로고만, 넓은 면적 금지.

### [카테고리별 서브 액센트]
레이아웃·시스템 동일 유지, 카테고리1=틸 #2D6A6A / 카테고리2=블루베리 #3F5E9E / 카테고리3=플럼 #8A4A6B. 적용 범위 딱 3곳: ①요약 카드 숫자 색 ②사이드바 선택 메뉴 왼쪽 3px 라인 ③목록 학년/상태 뱃지(연한 틴트 배경+진한 텍스트). 코럴은 카테고리 바뀌어도 불변. 서브 액센트도 상수 파일에서 카테고리별 매핑.

### [동작]
카테고리 클릭→사이드바 세트 교체+서브 액센트 전환(부드러운 transition). 사이드바 클릭→메인 전환. 필터 토글→목록 필터링. mock 데이터 10개(더미 JSON), API 교체 쉽게 데이터 로직 분리. 상태는 useState/useContext 수준.

### [작업 순서]
①상수+레이아웃 뼈대 ②디자인 시스템(컬러·폰트) ③메인 콘텐츠(요약카드+필터+목록) ④서브 액센트 전환 로직 ⑤mock 데이터·인터랙션 — 각 단계 확인받기.
