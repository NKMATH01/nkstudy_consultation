### 도중에 바꾼 설계
**분석지를 HTML 이 아니라 JSON 으로 저장.** `report-viewer-client.tsx:26` 이 저장된 HTML 을 `innerHTML` 로 주입하는데, 이 분석지 내용은 학생 시험지 사진에서 읽어낸 것이라 신뢰할 수 없다(학생이 여백에 `<img onerror>` 를 써 두면 학부모 브라우저에서 실행). JSON + React 렌더로 바꿔 경로를 막았고, 덤으로 학생마다 디자인이 통일된다.

### 못 한 것 · 남은 위험
- **마이그레이션 미적용** — 실제 올리기 · exam:pull/push · 분석지 렌더 · 카톡/링크 버튼은 표가 생긴 뒤에야 끝까지 확인 가능

- 모바일 카메라 앱에서 여러 장 동시 선택은 실기기 미확인
- 사진 회전 기능 없음(입장 점검 🟡, 범위 밖으로 보류)
- **알림톡 자동 발송은 범위 밖** — 기존 `analysis_result` 템플릿은 변수가 맞지만 제목이 "학습성향 검사 결과" 로 박혀 있어 새 템플릿 신청 필요(카카오 승인 대기)
- 루틴 운영 실수: 팀장이 빌드 검증 후 `.next-verify` 를 안 지워 린트가 30 → 21,850 건으로 폭증. 확인 후 삭제해 원복. **빌드 검증 직후 산출물을 지울 것.**
