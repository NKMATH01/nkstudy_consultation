## ★ 다음 작업 — 보고서 결과물 수정 (사용자 지시)

사용자가 **"보고서 결과물이 마음에 안 든다, 이것 수정부터"** 라고 했다.
확인 결과 **둘 다 고쳐야 하며 학부모 결과지가 먼저다.**

1. 학부모 결과지 재설계안 (`Main.dc.html` / 아티팩트 `c3349c86…`) — **먼저**
2. 점검 보고서 (`nk-learning-assessment-review.html` / 아티팩트 `00389fb1…`) — 그다음

**무엇이 불만인지는 아직 듣지 못했다.** 고쳐 놓고 보여주지 말고 **어디가 마음에 안 드는지부터 물어라.**
이미 방향을 두 번 바꿨다 — 1판은 쉬운 안내문 톤이었고 2판은 전문 진단 톤이다. **세 번째도 짐작으로 가면 또 어긋난다.**

## 틀리면 안 되는 전제 4가지

1. **검사 대상은 입학테스트 보러 온 신입생이다.** 우리 학원에 숙제·출결 기록이 하나도 없다. 내부 기록 대조는 등록 4주 후에나 가능하고, 그때도 개인 해석용이 아니라 검사 보정용이다.
2. **가장 중요한 판단은 "의지가 제대로 있는가"** 다.
3. **3점(절반쯤 했다)은 '보통'이 아니라 '못한다'에 가깝다.**
4. **결과지는 전문적이어야 한다** — 학부모가 "우리 아이를 잘 파악하고 있구나" 하고 느껴야 한다.
