## 설계 요지

- **질문 아홉 개에 답한다** — 학습 태도 · 숙제 태도 · 목표 의식 · 어려운 점 · 단기 회복력 · 질문 성향 · 학습 방해와,
  가장 중요한 두 가지 **철저한 관리를 버틸 수 있는가** · **강하게 밀어도 되는가, 다독여야 하는가**.
  뒤의 두 가지는 02에서 배지 + 한 문장 + 학생 본인 답으로 먼저 답한다.
- **판단 표현** — 항목별 3등급. `잘 되고 있음`(75 이상) / `지켜볼 것`(62.5 이상) / `먼저 도울 것`(그 아래).
  **"절반쯤 했다"는 '보통'이 아니라 '먼저 도울 것'** 이다.
- **직접 물어본다** — 관리 수용은 `NK는 … 버틸 수 있겠어요?` 4지선다로, 지도 방식은 두 선생님 중 고르는 강제선택으로
  학생에게 그대로 묻고, 점수에 넣지 않고 답 그대로 판정에 쓴다.
- **MBTI는 섹션을 없앴다** — 07 종합 소견의 한두 문장으로만 남기고 원인으로는 쓰지 않는다. 표지의 MBTI 행도 뺐다.
- **입학 상담 확인 목록은 뺐다** — 그 자리에 **학부모 질문 일곱 개**를 넣었다(강한 학습 선호 · 결과지 동의 여부 ·
  연락 주기 · 요구에 끌려가는지 · 대학 목표 · 목표 점수 · 힘들어할 때 원하는 대응). 점수는 내지 않는다.
- **학생 주관식·입력은 전부 유지** — `intakeSchema` 33개 필드 + `commitment14` 를 하나도 빼지 않는다.
  학부모에게 보일 것만 05에 싣고, 운영 정보(연락처·통학·시간대·소개 경로)는 결과지에 싣지 않는다.
- **문장** — 소견서 톤(`~로 나타났습니다`)이되 **초등학생도 아는 낱말**로, 한 문장에 한 뜻. 유형 이름·MBTI 원인·점수 숫자 금지.
- **문항 원문은 한 줄도 싣지 않는다** — 그래프 라벨은 짧은 이름만 쓴다.
- **그래프 8종** — 응답 분포 스택 막대 · 8축 레이더 · 3구간 띠 9행 · 지도 방식 사분면 · 문항 점 스트립 8벌 ·
  수학 전략 미니 바 · 12주 타임라인 · 학부모 질문지의 빈 칩. 전부 인라인 SVG 또는 CSS이며 외부 리소스는 웹폰트뿐이다.
- 색·크기는 `src/components/analysis-report-v2/report-theme.ts` · `report-premium-css.ts` 값 그대로
  (navy `#152033` / brass `#b88a32` / teal `#2d776a` / coral `#a8433d` / 바탕 `#e8e9e6` / 본문 14.5px).
- **코드 반영은 아직 하지 않는다** — 2026-09-01 미커밋 56건의 처리 방향이 정해진 뒤다.
  새 ID가 옛 ID와 글자가 겹치므로(문항표 §5의 경고) 옛 응답과 절대 섞지 않는다.
