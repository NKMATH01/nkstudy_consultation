## 설계 요지

- **닮을 모양** — 심리검사 결과보고서(프로파일 + 척도별 해석 + 전문가 소견). 단 **규준·T점수·백분위는 없다.** 우리 검사는 규준이 없다. 학부모에게 숫자를 보이지 않는다.
- **판단 표현** — 항목별 3등급 + 문항 자리 그래프. `잘 되고 있음`(75 이상) / `지켜볼 것`(62.5 이상) / `먼저 도울 것`(그 아래). **"절반쯤 했다"는 '보통'이 아니라 '먼저 도울 것'** — 이번 개편의 핵심 교정이다.
- **의지가 주인공** — `계획 이어가기`(G1~G4) + `틀린 뒤 다시 시작`(B1~B4)을 프로파일 바로 다음 **핵심 소견**으로 올렸다.
- **톤** — 소견서. `~로 나타났습니다` / `~를 확인합니다` / `~부터 시작합니다`. 해요체·위로 금지.
- **전제** — 검사 대상은 입학테스트를 보러 온 신입생. 학원 기록이 없어 행동 관찰 기회는 **입학테스트 한 번**뿐이다. "첫 2주 관찰"·"숙제 기록 대조"는 성립하지 않는다.
- **금지(§10)** — 유형 명명·낙인 금지. 판정은 **행동 단위**로만 내리고, 근거는 문항 문장 대신 그래프의 문항 자리로 보인다.
- 그래프 라벨은 `src/lib/assessment/v2/definition.ts` 의 `evidenceLabel`, 12주 계획 문구는 `src/lib/assessment/v2/transition-plan.ts` 의 `PLAN_BY_CONCERN` 에서 가져왔다. **문항 원문(`text`)은 결과지에 한 줄도 싣지 않는다.**
- **답변 인용 제거(2026-09-04 피드백)** — 문항 문장과 고른 답을 그대로 보여 주던 "학생 답변 근거"를 03·04·05·07·09에서 전부 뺐다. 역채점 문항은 뒤집은 값으로 찍고 각주로 밝힌다.
- **그래프 9개** — 응답 분포 스택 막대(A) · 7축 레이더(B) · 3구간 띠(C) · 의지 2축 사분면(D) · 문항 점 스트립(E, 7벌) · 선호 스펙트럼(F) · MBTI 4축 병치(G) · 수학 전략 미니 바(H) · 12주 타임라인(I). 전부 인라인 SVG 또는 CSS이며 외부 리소스는 웹폰트뿐이다.
- **새 섹션 3개** — 08 학생이 직접 쓴 주관식 답(설문 라벨 그대로, 학원명 제외) · 06 MBTI 성향(설문과 병치해 일치 여부만) · 11 등록 시 12주 운영 계획(안).
- **감사 문서와 다르게 간 것은 사용자 결정** — 2026-09-01 감사 문서는 학부모 결과지에서 MBTI 축과 12주 계획을 뺐다. 2026-09-04 사용자 결정으로 둘 다 넣되, MBTI는 등급·점수 무관을 명시한 병치 표시로만, 12주는 제목에 **(안)** 을 붙여 §4·§10 원칙은 지켰다.
- 색·크기는 `src/components/analysis-report-v2/report-theme.ts` · `report-premium-css.ts` 값 그대로 (navy `#152033` / brass `#b88a32` / teal `#2d776a` / coral `#a8433d` / 바탕 `#e8e9e6` / 본문 14.5px).
