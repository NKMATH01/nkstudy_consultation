## 설계 요지

- **닮을 모양** — 심리검사 결과보고서(프로파일 + 척도별 해석 + 전문가 소견). 단 **규준·T점수·백분위는 없다.** 우리 검사는 규준이 없다. 학부모에게 숫자를 보이지 않는다.
- **판단 표현** — 항목별 3등급 + 근거 응답. `잘 되고 있음`(75 이상) / `지켜볼 것`(62.5 이상) / `먼저 도울 것`(그 아래). **"절반쯤 했다"는 '보통'이 아니라 '먼저 도울 것'** — 이번 개편의 핵심 교정이다.
- **의지가 주인공** — `계획 이어가기`(G1~G4) + `틀린 뒤 다시 시작`(B1~B4)을 프로파일 바로 다음 **핵심 소견**으로 올렸다.
- **톤** — 소견서. `~로 나타났습니다` / `~를 확인합니다` / `~부터 시작합니다`. 해요체·위로 금지.
- **전제** — 검사 대상은 입학테스트를 보러 온 신입생. 학원 기록이 없어 행동 관찰 기회는 **입학테스트 한 번**뿐이다. "첫 2주 관찰"·"숙제 기록 대조"는 성립하지 않는다.
- **금지(§10)** — 유형 명명·낙인 금지. 판정은 **행동 단위**로만 내리고 근거 응답을 함께 붙인다.
- 문항 원문은 `src/lib/assessment/v2/definition.ts`, 답 라벨은 `src/lib/assessment/v2/display.ts` 의 `SCALE_LABELS_V2` 를 글자 그대로 옮겼다.
- 색·크기는 `src/components/analysis-report-v2/report-theme.ts` · `report-premium-css.ts` 값 그대로 (navy `#152033` / brass `#b88a32` / teal `#2d776a` / coral `#a8433d` / 바탕 `#e8e9e6` / 본문 14.5px).
